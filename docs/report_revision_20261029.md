# 报告样式与写作调整说明

本次以人工修订报告的黄底、红字和删除标记为修改依据，以新的机械臂状态报告示例为版式和图下解释参考。示例中的故障、数值、单位和波形描述不作为本案例的实测事实。

## 正式报告

保留结论摘要、设备与数据范围、相关振动趋势、相关图谱、综合判定、检维修措施和参考源。没有入选图表的图谱章节不生成，章节顺序连续编号。

标题使用设备名称，副标题使用安装区域与实际历史时间范围。台账保持三行布局，采集工况保留运行与停机的记录占比。名称含“模拟”的源台账原文不改写为数据性质。

删除首末值表、倍频坐标明细表、逐条规则及满足次数、CSV路径和来源行号、编制方式、模型输入说明、输入输出映射以及固定的“数据缺口”段落。后台的原始数据、检查结果、全部逐时刻匹配、输入上下文和引用仍保留，可通过“依据”“写作输入”与“核查资料”查看。

结论用“存在……的可能”“疑似”“高度疑似”等与规则支持相符的措辞。部分条件满足不能直接写成“大概率”；历史较高支持单独标注，不当作当前故障。不会把满足率变成故障概率或严重程度。

## 图表与机理含义

最近或历史最高满足率至少二分之一的机理方向作为报告重点，展示这些方向全部条件涉及的输入指标，包括未满足条件；此阈值只用于报告内容筛选，不改变规则阈值或原匹配结果。弱支持方向保留在核查资料中。图表输入缺失时不补图。

趋势图按实际采集时间连接原始点，频谱按原频率坐标连线。不重采样、不填补缺口，不将跨时段连线解释为连续采集。当前四类机理的条件不使用波形形态，因此不会仅因上传了波形就固定插入波形图。

每张图下均附“机理含义”，解释相关特征与故障的联系、实测支持或不足。解释与图表编号一一对应，引用限定为相关机理；未发送图像或形态分析结果时，不得描述目视观察到的冲击、周期波形等。历史频域相关判断仍以最新频谱为共同参考。

## 提示词与验证

正式提示词统一保存为 docs/report_writer_prompt.md，运行时直接读取，实际请求同时归档在每份报告的 writer_input.json。新增 assessment 和 chart_explanations 输出字段。对图表覆盖、知识引用、数字、过强结论及过程性文字进行校验；未通过时使用明确标记的固定说明，并在核查资料中展示原因。

全部知识继续进入上下文，重复统计通过规则和条件编号关联。超过配置预算时明确报错，不静默截断。

回归检查覆盖按相关性选图、历史中间记录、弱支持与无图、错误或遗漏图解释、错误知识引用、编造数值、过程性文字和超长上下文。真实案例还需实际调用模型并逐页核验 Word/PDF。
