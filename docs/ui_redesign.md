## 操作方式

- 左侧选择 ZIP，点击“导入并检查”；样例下载入口可以展开，包含四组模拟案例。
- 检查信息采用标签和值的两列布局，原始波形有无、转速缺失及输入差异分别显示。分析限制、当前特征核对默认折叠。
- 桌面左栏的编制操作固定在底部，台账区域可独立滚动。执行步骤可展开查看。
- 顶部知识文档、诊断规则入口保留独立对话框，并显示打开状态；知识条数来自接口实际结果。
- 右侧以蓝色摘要区显示结论与关键数值。特征表的数值右对齐、使用等宽字体；表格只保留行分隔线。
- 预览操作栏提供“查看 PDF”“下载 Word”，依据和写作输入为文字链接。
- 打开已有报告链接时，自动恢复其归档案例的检查信息。归档信息不等同于重新上传，重新生成前仍需上传 ZIP。
- 窄屏改为上下布局；宽表在自身容器内横向滚动。
