## 部署与版本校验

在项目根目录执行：

```bash
sha256sum inputs/reference.docx
```

结果应与上方 SHA256 一致。导出程序会校验模板版本并依赖其段落和表格槽位，不要用任意 Word 文档替换，也不要重新保存此文件。需更换模板时，应同步修改导出逻辑的槽位和哈希校验，并验证导出版式。

模板中的示例文字和图片用于排版，不是本次诊断的输入数据。机理知识文档仍需另行从网页导入；密钥、客户输入包和生成报告不随此模板提交。
