# 报告图表规范

图表由 Matplotlib 按输入坐标确定性绘制，不由大模型生成。真实采集与派生测试使用相同版式，测试图保留性质标记。

- 白底、深蓝折线、浅灰水平网格，统一坐标字体、日期格式、线宽和留白。
- 趋势图使用真实时间间隔，连接全部原始点，不平滑、不插值、不重采样；超过 40 条记录时省略圆点符号，折线仍保留全部顶点。线段不表示间隔内连续实测。
- 从报告中已匹配方向的规则读取直接指标条件，以浅色区域和虚线表示，区间开闭按图例的比较符号解释。该区域不是行业报警等级，也不代表单项满足即可确诊。
- 比值条件不转成分子或分母的阈值；未匹配方向、未执行规则不增加阈值。频谱及波形保持客户原坐标，不复算信号。
- PNG 为 300 dpi，阅读版尺寸 2850×990；同目录保存 SVG 矢量原图，供后续排版使用。网页、Word、PDF 使用同一 PNG，保持原报告图宽和比例。
- 图表风格调整不改变规则结果、模型正文、引用、客户数值或原报告。历史报告保留，验证时新建版本并记录原报告编号。

固定值会形成平台，稀疏采集点之间会形成长直线；不能为改善外观而增加波动或补充观测。
