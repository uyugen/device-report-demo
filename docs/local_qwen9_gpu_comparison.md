# 9B GPU报告对比服务

本轮使用同一张物理GPU 5（RTX A6000），分批运行Qwen3.5-27B与Qwen3.5-9B的Q4_K_M量化权重。推理运行时均为llama.cpp b12065的CUDA 11.8构建，八个CPU线程、单并发、65536 tokens上下文、q8_0缓存、Flash Attention、相同batch与microbatch。9B文本服务只处理本机请求。

9B GPU独立目录为`/data1/tjb/qwen9-gpu`，端口`127.0.0.1:8058/v1`，配置为`config/qwen9_gpu.json`，启动器为`scripts/local_model9_gpu_service.py`。9B原CPU服务8056保留，本轮比较不调用该端口。GPU运行时与权重复用既有已验证文件，不修改系统CUDA和其他任务。

9B GPU显存预算12288 MiB，启动要求至少20480 MiB空闲，显卡剩余低于2048 MiB或服务超过预算时停止本用户进程。启动时检查本项目27B是否仍运行，要求先轮换；不停止其他用户进程。该保护是轮询，不是驱动级硬隔离。

在项目根目录执行：

```bash
.venv/bin/python scripts/local_model9_gpu_service.py status
.venv/bin/python scripts/local_model9_gpu_service.py start
.venv/bin/python scripts/local_model9_gpu_service.py stop
```

轮换前确认报告队列为空。批量程序先完成27B报告，再停止27B、启动9B GPU；结束后停止9B GPU并恢复原先运行的27B服务。生产`.env`及网页默认模型保持原配置。

本轮20份输入使用现行1.2格式，覆盖正常、滚动轴承故障、转子不平衡、连接松动、不对中及连接松动五类，每类四份。全部历史记录与最近记录保持相同机理判定；数据齐全，不设置缺失或阈值临界。波形与最终特征、频谱相互核验。按用户要求，包内不添加测试或模拟属性，也不在案例名称写入预期故障答案。

两个模型使用完全相同的事实、16条知识、系统提示词、写作提醒及JSON Schema，temperature为0.2，固定seed为20261105，关闭思考；本轮显式设置cache_prompt=false，并核查供应商返回的缓存计数。全部首轮请求移除model字段后的哈希须一致，重写采用相同校验策略。

模型写作采用率和首轮校验通过率反映当前完整流程表现，不是诊断准确率；诊断来自确定性机理规则。报告质量需结合原文审核，不仅看JSON通过率。输入包、生成报告、原始请求及私有API凭证均不提交源码仓库。

## 本轮执行结果

20对初始请求除模型名外一致，全部模型请求缓存计数为零。40份报告均完成导出并检查Word图片、03节健康度图顺序及正文无测试标记。网页抽查覆盖两模型各五类情况，共10份。

9B模型正文采用12/20，首轮通过4/20，固定说明回退8份，平均端到端27.1秒，观测显存峰值6626 MiB。27B模型正文采用19/20，首轮通过15/20，回退1份，平均端到端46.8秒，观测显存峰值18258 MiB。耗时包含重写和导出，回退也计入；不将这些数字作为诊断准确率。两者仍有人工复核发现的措辞和机理解释问题。

批量结束已停止本轮9B GPU实例，恢复默认27B服务。9B GPU目录和配置保留，原CPU服务不参与本轮对比。
