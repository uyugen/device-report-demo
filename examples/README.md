# 部署验收资料

本目录用于独立安装后的流程验收，不包含客户原始数据或原始知识 DOCX。案例由程序构造，不代表真实设备故障；输入中不预置诊断答案，预期结果单独保存在 `manifest.json`，不会作为案例上传给报告系统。

| 文件 | 使用方式 | 预期结果 |
| --- | --- | --- |
| deployment_knowledge.docx | 在“知识文档”入口上传 | 导入电动机的四条知识，名称和规则原文与仓库规则对应 |
| normal.zip | 在“案例数据上传”入口上传 | 当前正常，24个历史时刻均正常 |
| bearing_fault.zip | 同上 | 当前轴承故障，历史16次正常、8次轴承故障 |
| historical_fault.zip | 同上 | 当前正常，历史16次正常、8次轴承故障；保留历史故障相关图文 |

每个案例采用1.2版结构，包含七类特征历史、最新波形、最新频谱和健康度，共十组数据。24个历史时间点完全对齐；最新波形采样率2048 Hz、4096点、时长2秒；转速3000 r/min。健康度图应始终位于第03节最后。

最新波形的有效值、峰值、峭度和偏度与历史末次对应值一致。速度有效值、低频冲击值和健康分数为独立构造的接口最终值。频谱也是独立提供的参考数据，**不是最新波形的 FFT**；用于验证输入接口和精确倍频坐标匹配，不用于验证信号处理精度。所有历史时刻明确共用这份最新频谱参考，不能解释为各时刻实测频谱。

知识文档的四条规则原文来自已入库的 `config/rules.json`，机理现象、原因与措施为部署验收用简要说明，不是企业完整知识库或新增行业标准。规则仍只由独立配置执行，上传文档不会自动启用新规则。

安装依赖后，可执行 `python scripts/check_deployment.py --require-pdf` 核查文件、规则结果及环境。完整页面与导出验收见[部署说明](../docs/deployment.md)。如需重新生成本目录文件，执行 `python scripts/build_deployment_examples.py`；重新生成会同时更新知识文档、案例包和文件指纹，需一并提交。
