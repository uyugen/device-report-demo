# 设备状态报告生成工作台

使用客户最终值，按全部历史记录逐时刻匹配电动机机理规则；历史共用用户指定的最新频谱参考。故障方向及支持等级由程序计算，大模型撰写解释和建议。支持网页、Word、PDF与逐次明细CSV。

见[使用与规则口径](docs/real_case_format.md)、[模板约定](docs/artifact.md)、[正式报告写作提示词](docs/report_writer_prompt.md)及[本次调整说明](docs/report_revision_20261029.md)。

报告根据可能故障筛选相关特征图，连接原始坐标点，并为每张图编写“机理含义”。正式正文保留结论、台账、图文解释、措施与参考源，全部规则明细和数据检查在网页“核查资料”中查看。模型写作必须通过图表覆盖、对应引用、数字和结论边界检查。

原模拟样例已移除。密钥、客户数据、知识原文和运行报告不入库。
